WiFiCloneLab files

These files preserve the code snippets as they appeared in the message, without repairing or reformatting them.
Important: several snippets are visibly truncated or have multiple Python statements merged together, so this package will not run as-is. A complete runnable project requires the missing portions of the original code.

Security note: a Telegram bot token was included in the supplied text. Treat it as exposed: revoke/regenerate it with BotFather before using Telegram alerts, and only store the replacement in the environment variable TELEGRAM_BOT_TOKEN.
